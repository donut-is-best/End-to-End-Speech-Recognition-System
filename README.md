# end-to-end-speech-recognition-system
中文名称：端到端语音识别系统

## 项目简介
独立完成端到端语音识别系统，输入音频，直接输出对应的文本，不需要拆分传统语音识别的声学、语言模型分步流程。
本人独立负责数据集预处理、模型调用/搭建、音频特征提取、模型推理、识别效果测试与调优。

## 技术栈
- 语言：Python
- 框架：PyTorch
- 音频处理：Librosa
- 模型：端到端ASR模型

## 项目亮点
1. 搭建端到端语音识别流程，原始音频输入，直接输出转录文本，简化传统ASR多阶段处理链路
2. 完成音频预处理：降噪、重采样、音频特征提取，提升模型识别准确率
3. 在测试数据集上完成模型推理，对比不同音频样本的识别效果，针对错字问题做参数调优
